## 2. 提效测量方法

选一个真实任务，分别用「传统方式」和「CiteSeek」各做一次，记录耗时：

| 任务 | 传统方式 | CiteSeek | 记录方式 |
| --- | --- | --- | --- |
| 在 3 份讲义中找到「KV cache 压缩」相关段落及页码 | 逐份打开、搜索、记页码 | 输入问题 → 引用直接给页码 | 秒表 + 录屏 |
| 组会前整理「B+ 树 vs 哈希索引」的对比要点 | 手翻 PDF 摘录 | 提问 → 复制带引用结论 → 导出 Markdown | 秒表 + 导出文件 |
| 找回上周读过的某段结论 | 凭记忆翻文件 | 检索命中 + 原文高亮 | 秒表 |

建议至少 3 位用户、每人 2 个任务，记录「开始时间、结束时间、是否正确、是否找到出处」。

## 3. 站内可核对数据

```bash
curl http://127.0.0.1:8080/api/stats
```

返回文档数、页数、文本块数、索引状态；检索与问答次数可从 `searches`、`answers` 表统计：

```bash
cd deploy
docker compose exec seekdb mysql -uroot -P2881 -e \
  "SELECT COUNT(*) AS searches FROM citeseek.searches; SELECT COUNT(*) AS answers FROM citeseek.answers;"
```

Qoder Sites 发布后，可在站点后台「访问统计」查看访问次数与独立访客，截图作为来源。
