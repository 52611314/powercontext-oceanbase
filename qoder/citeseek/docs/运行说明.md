# 运行说明

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11、macOS 或 Linux |
| Docker | Docker Desktop 24+（Windows 需启用 WSL2） |
| 内存 | ≥ 4 GB 可用（seekdb 容器默认 2 GB） |
| 磁盘 | ≥ 2 GB（镜像约 600 MB，模型 24 MB） |
| 网络 | 仅首次构建需要（拉取 `oceanbase/seekdb` 与 Python 依赖）；运行期不联网 |
| Node.js | **不需要**。前端产物已预构建并随仓库提交 |

## 2. 一键启动

```bash
cd qoder/citeseek/deploy
docker compose up -d --build
```

首次启动会拉取 seekdb 镜像并构建应用，通常 2–5 分钟；之后启动约 30 秒。

检查状态：

```bash
docker compose ps
curl http://127.0.0.1:8080/api/ready
# {"ok":true,"checks":{"seekdb":"ok","embedding":"ok"},"dim":512}
```

访问：

| 入口 | 地址 |
| --- | --- |
| 界面 | <http://127.0.0.1:8080> |
| API 文档 | <http://127.0.0.1:8080/docs> |
| 健康检查 | <http://127.0.0.1:8080/api/health> |
| seekdb（MySQL 协议） | `127.0.0.1:2881`，用户 `root`，空密码 |

> seekdb 只监听 127.0.0.1，避免把数据库暴露到局域网。

## 3. 导入示例资料

仓库已包含 3 份中文示例 PDF（自撰，见 `samples/notes/*.md`）：

- `samples/papers/db-index.pdf` 数据库索引与查询优化
- `samples/papers/llm-inference.pdf` 大模型推理优化讲义
- `samples/papers/hybrid-retrieval.pdf` 向量检索与混合检索实践

在界面「文献库」直接拖拽上传即可。也可以脚本导入：

```bash
pip install httpx
python scripts/verify_library.py http://127.0.0.1:8080
```

如需从 Markdown 重新生成 PDF（可选，需要 `pip install reportlab`）：

```bash
python scripts/make_samples.py
```

## 4. 验收脚本

```bash
pip install httpx
python scripts/verify_library.py http://127.0.0.1:8080   # 导入 3 份 PDF 并核对索引
python scripts/verify_search.py  http://127.0.0.1:8080   # 三种检索模式 + EXPLAIN 证据
python scripts/verify_ask.py     http://127.0.0.1:8080   # 问答、引用偏移、导出、原文访问
python scripts/evaluate.py       http://127.0.0.1:8080   # Hit@10 / MRR / 章节召回
```

每个脚本都会打印 `OK` 并以 0 退出。

## 5. 数据与证据

| 位置 | 内容 |
| --- | --- |
| `data/uploads/` | 上传的原始文件（容器内挂载为 `/data/uploads`） |
| `data/logs/retrieval.jsonl` | 每次检索的查询、过滤、通道、耗时、Top5 命中 |
| `docs/evidence/search-evidence.json` | 三种模式的 SQL 与 EXPLAIN |
| `docs/evidence/retrieval-eval.json` | 评测逐条结果 |
| `docs/检索评测.md` | 评测报告 |

直接查库：

```bash
cd deploy
docker compose exec seekdb mysql -uroot -P2881 -e \
  "SELECT doc_id, page, section, LEFT(text, 40) FROM citeseek.chunks LIMIT 5"
```

## 6. 配置项

全部通过环境变量配置，默认值见 `deploy/.env.example`。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CITESEK_SEEKDB_HOST` / `PORT` | `seekdb` / `2881` | 容器内主机名 |
| `CITESEK_SEEKDB_USER` / `PASSWORD` | `root` / 空 | 示例环境未设密码 |
| `CITESEK_SEEKDB_DB` | `citeseek` | 数据库名 |
| `CITESEK_DATA_DIR` | `/data` | 原始文件、日志 |
| `CITESEK_MODEL_DIR` | `/app/backend/models/bge-small-zh-v1.5` | 内置嵌入模型 |
| `CITESEK_MAX_UPLOAD_MB` | `100` | 单文件上限 |
| `CITESEK_CHUNK_SIZE` / `OVERLAP` | `420` / `80` | 切块参数 |
| `CITESEK_EMBED_BATCH` | `16` | 嵌入批大小 |
| `CITESEK_INDEX_WORKERS` | `2` | 并行索引线程数 |

## 7. 停止与重置

```bash
cd deploy
docker compose down          # 停止，保留数据
docker compose down -v       # 停止并删除 seekdb 数据卷
rm -rf ../data               # 删除上传文件与日志（可选）
```

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 8080 / 2881 端口被占用 | 修改 `deploy/docker-compose.yml` 中 `ports` 的宿主机端口 |
| seekdb 一直不健康 | 确认 Docker 可用内存 ≥ 4 GB；`docker compose logs seekdb` |
| `docker compose up` 卡在拉镜像 | 配置 Docker 镜像加速，或先 `docker pull oceanbase/seekdb:latest` |
| 页面打不开但容器正常 | 等待 `/api/ready` 返回 ok；首次启动需加载嵌入模型 |
| 上传后一直「索引中」 | 查看 `docker compose logs -f app`；确认 PDF 不是扫描件 |
| 想换嵌入模型 | 替换 `backend/models/` 下模型并重建镜像，表结构维度需保持 512 |

## 9. 本地开发（可选）

```bash
# 后端
cd backend
pip install -e ".[dev]"
PYTHONPATH=src uvicorn citeseek.main:app --reload --port 8000

# 前端（另开终端）
cd frontend
npm install
npm run dev        # http://127.0.0.1:5173，/api 代理到 8000
```

修改前端后需要 `npm run build` 才会更新后端托管的产物；Docker 镜像直接使用 `frontend/dist`，因此改完前端要重新 `docker compose build app`。
